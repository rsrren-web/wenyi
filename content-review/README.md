## 来源与取舍

1. 公版古籍《周易》原文，维基文库各卦页面与版本号见 `classical-sources.json`。只使用古代原文，不复制现代解释。
2. 第二份全文转录用于交叉比对：https://guoxue.app/ja/library/classics/liuyao/zhouyi 。不以单一网络转录作为所有异文的裁决依据。
3. 王弼、韩康伯注、孔颖达疏《周易正义》，李学勤主编《十三经注疏（标点本）》扫描本，用于争议处复核。下载地址：https://www.zzrvtc.edu.cn/_upload/article/files/23/22/649f8f1c47f0b8de10c28f940cc7/caca5921-2d6d-4017-8869-4a06577ab43e.pdf 。未把扫描本或现代整理说明重新发布到网站。

扫描本核对位置（书内页码）：

- 第 63 页：履彖传不多录“利贞”，大象为“定民志”。
- 第 104–105 页：贲卦辞“有攸往”；此本彖传收录“刚柔交错，天文也”。
- 第 120 页：大畜九二“輹”、九三“日闲舆卫”。
- 第 130、133 页：坎彖传“险之时用”；九五采用此本“祗既平”。
- 第 153 页：晋九四“鼫鼠”。
- 第 169 页：解彖传“解之时大矣哉”，不增“义”。
- 第 202–203 页：革采用“己日”“革而信之”“革之时大矣哉”。
- 第 246 页：小过“有飞鸟之象焉，飞鸟遗之音”。

说明：古籍存在异体、通假、版本和断句差异。保留“取／娶”“遯／遁”等可通表达，不将所有差异机械列为错字。渐上九保留项目原有“逵”这一解释传统，其他本作“陆”；白话解按高远处解释。乾彖传采用通行“太和”，有本作“大和”。现代标点不作为古代原文的一部分。不能据自动化测试宣称完成了所有版本的学术定本校勘。

## 展示与日历

彖传置于卦辞后；大象与每爻小象分开标注；小象进入桌面爻辞单元格和移动端折叠卡，避免再增加窄列。两种详情页复用同一组件。

设备当地阳历、时钟、当地日期对应的农历及时辰继续保留。四柱独立把同一时刻转换为 `Asia/Shanghai`：立春精确交接换年、节精确交接换月、23:00 子初换日，不校正真太阳时。使用 lunar-javascript 的 EightChar sect 1，避免手算时柱与日柱口径混杂。来源：https://6tail.cn/calendar/lunar.ganzhi.html 。
