# 问易

纯静态《易经》六十四卦查询与起卦应用。

## 永久零付费约束

- 不使用 API token、密钥或任何付费 API。
- 不使用数据库、云函数、后台服务器或第三方计费 SDK。
- 不在运行时请求外部数据或字体；卦象 JSON、图片与字体回退均随浏览器或操作系统提供。
- 托管仅使用公开仓库的免费 GitHub Pages。
- 后续新增依赖前必须确认其不需要账户、token、订阅或按量计费服务。

## 共享详情与起卦记录

- `HexagramDetails` 是两种详情入口唯一的正文组件，统一展示卦象身份、情势研判与宜忌、经典文本、综合解读、图像、六爻、关联卦象和浏览导航。
- `/hexagrams/:id` 只按卦号读取本地资料；`/divination` 读取已保存的起卦记录，并在同一正文上增加所问问题与生成图片按钮。
- 只有首页主动提交才随机选择卦象。问题、卦号、记录 ID 和时间一同保存到 `sessionStorage` 的 `wenyi.divination.v1`；刷新或返回结果页不会重新抽取。再次主动起卦会覆盖当前标签页的上一条记录，不提供历史记录列表。
- 记录限当前标签页会话，并非永久存档。直接打开结果页而没有有效记录时会提示回首页，不自动生成结果；旧版仅保存问题的记录也不会被误认为已有卦象。
- 上一卦、下一卦进入普通资料详情，不携带问题或下载按钮，也不修改起卦记录。关联卦象通过原生链接在新标签页打开。
- 图片是问题、卦象身份、情势研判及宜忌的摘要卡片，不是整页截图；在浏览器本地生成，不上传问题或调用外部服务。

## 检查与发布

使用 Node.js 24 执行自动测试（测试直接导入 TypeScript 记录模块）：

```sh
node --test tests/*.test.mjs
node node_modules/typescript/bin/tsc --noEmit
node node_modules/vite/bin/vite.js build --configLoader runner
node scripts/prepare-pages.mjs
```

自动测试覆盖记录创建与稳定读取、缺失/损坏/不可用存储、64 卦必填内容、384 爻、关联引用和图片资源。浏览器回归另核对同一卦两种入口的正文一致性，以及刷新、返回、新标签页、目录、图片下载和手机布局。

`prepare-pages.mjs` 仅重新生成 `docs/` 发布目录，清理旧哈希资源，并生成 GitHub Pages 深层路由使用的 `404.html`。源代码与数据不在该清理范围内。
